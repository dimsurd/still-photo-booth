# 📸 Still – A Minimalist Photobooth Web App

**Still** is a clean and minimal photobooth web application built with **Next.js**, designed to let users take four timed photos with real-time filters — just like a classic photo booth, but in your browser.
 
## ✨ Features

- 🎥 **Live Webcam Feed** with optional real-time filters
- ⏱️ **Countdown Timer** before each photo capture
- 💡 **Screen Flash Effect** on photo snap
- 🖼️ **4-Photo Grid** that updates with each new capture
- ❌ **Delete & Retake** individual photos
- 🎨 **Filter Controls** (Monolog, Sepia, Vintage)
- 🎠 Optional **Carousel View** using `shadcn/ui`

---

## 🧰 Tech Stack

- [Next.js](https://nextjs.org/)
- [React Webcam](https://www.npmjs.com/package/react-webcam)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/) for modern, accessible UI
